# Vista 3D (Libreria)

La categoria Vista 3D contiene solo nodi correlati agli HDRI proiettati a livello sferico, utilizzati nella Vista 3D di Substance 3D Designer o per l’esportazione in altre applicazioni come Substance 3D Painter.

Esistono due sottocategorie:

* **Ambienti HDRI**: non è disponibile alcuna documentazione, poiché si tratta esclusivamente di immagini destinate alla visualizzazione nella vista 3D, senza parametri aggiuntivi.
* **Strumenti HDRI**: nodi di strumenti per la creazione e la modifica di immagini HDRI sferiche. Funzione introdotta in SD 2019.2.
