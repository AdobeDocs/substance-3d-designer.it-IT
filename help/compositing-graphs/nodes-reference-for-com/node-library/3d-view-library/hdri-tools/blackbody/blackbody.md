## Descrizione

Converte la temperatura del colore da Kelvin a RGB. Con valori Kelvin più bassi vengono usati colori più caldi, con valori Kelvin più alti vengono usati colori più freddi.

## Parametri

* **Temperatura**: *1000.0 - 27000.0* Valore in gradi Kelvin che determina il colore.
