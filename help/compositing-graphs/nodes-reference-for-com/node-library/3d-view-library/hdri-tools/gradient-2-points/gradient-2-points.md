## Descrizione

Crea una sfumatura di 2 colori tra due punti selezionati dall’utente. Il risultato viene regolato in base alla proiezione sferica. Simile a [Gradient Linear (HDRI)](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/hdri-tools/gradient-linear-hdri/gradient-linear-hdri.md), ma con due punti invece di uno.

</td>
</tr>
</table>

<a name="parameters"></a>

## Parametri

|  |  |
|:---|:---|
| <b>Posizione Punto 1</b> | Prima posizione selezionata dall&#39;utente. Ha maniglia nella vista 2D. |
| <b>Colore Punto 1</b> <i>(valore colore)</i> | Colore all’inizio della sfumatura. |
| <b>Contrasto Punto 1</b> <i>0.0 - 1.0</i> | Contrasto della maschera del primo punto. |
| <b>Posizione punto 2</b> | Posizione del secondo punto selezionata dall&#39;utente. Ha maniglia nella vista 2D. |
| <b>Colore Punto 2</b> <i>(valore colore)</i> | Colore all&#39;estremità della sfumatura. |
| <b>Contrasto Punto 2</b> <i>0.0 - 1.0</i> | Contrasto della seconda maschera per punti. |
