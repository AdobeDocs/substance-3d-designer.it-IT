# Strumenti HDRI

Gli Strumenti HDRI sono nodi destinati alla manipolazione e alla creazione di immagini HDRI. In particolare, questi nodi dispongono di funzionalità per il funzionamento e la generazione corretti, valori High dynamic range e nodi che tengono conto e compensano il mapping proiezione sferica.
