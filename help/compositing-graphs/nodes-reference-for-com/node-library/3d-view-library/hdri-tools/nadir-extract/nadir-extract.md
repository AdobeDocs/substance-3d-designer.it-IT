## Descrizione

Estrae il punto centrale al suolo (nadir) di un’immagine di input con mappatura sferica. Può essere utilizzato per trasferire il bordo inferiore di un’immagine all’altra, mascherando la fotocamera o il treppiede.

## Parametri

|  |  |
|:---|:---|
| <b>Scala</b> <i>0.0 - 10.0</i> | Impostare il &quot;livello di zoom&quot; per il punto di terra |
| <b>Rotazione</b> <i>0.0 - 1.0</i> | Ruota attorno all’asse centrale. |
| <b>Gamma di output</b> <i>sRGB, lineare</i> | Gamma in uscita. |
