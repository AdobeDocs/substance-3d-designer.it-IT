## Descrizione

Regola automaticamente i livelli di input in modo da utilizzare l’intera gamma, dal nero al bianco. Ciò significa che il valore più scuro dell&#39;immagine verrà regolato sul nero pieno, mentre il valore più chiaro verrà regolato sul bianco pieno, massimizzando il contrasto.
