## Descrizione

Min Max trova i valori più chiari e più scuri di un input in Scala di grigio e li restituisce come [valori](../../../../../values-compositing-graphs/values-in-substance-compositing-graphs.md). È un&#39;alternativa manuale più granulare per [Livelli automatici](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/auto-levels/auto-levels.md), in cui puoi esporre gli input di valore di un nodo [Livelli](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) e inserirvi i valori di Min Max.

Per utilizzare questo nodo con un valore Levels, è necessario almeno sapere come utilizzare il menu a discesa [Parametro di esposizione](../../../../../../compositing-graphs/manage-parameters/exposing-a-parameter/exposing-a-parameter.md), nonché la [scheda di input Valore](../../../../../values-compositing-graphs/values-in-substance-compositing-graphs.md).

## Parametri

*Nessun parametro.*
