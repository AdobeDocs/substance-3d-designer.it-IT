## Parametri

|  |  |
|:---|:---|
| <b>Esempi</b> <i>1 - 128</i> | Impostate la qualità dell’effetto di sfocatura. |
| <b>Angolo</b> <i>0.0 - 0.5</i> | Imposta la quantità di &quot;rotazione&quot; dell’effetto. |
| <b>Posizione centrale</b> | Impostate il punto centrale dell’effetto. |
