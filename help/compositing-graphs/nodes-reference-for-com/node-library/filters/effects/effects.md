# Effetti

Questa categoria contiene un&#39;ampia gamma di nodi destinati a più utilizzi. Questi nodi sono principalmente destinati a un input a canale singolo ed eseguono un effetto o una modifica abbastanza avanzata come output.

Utilizza l&#39;<b>elenco di navigazione a sinistra</b> per sfogliare tutti i nodi in Effects.

Un ampio gruppo di nodi è destinato all&#39;elaborazione, alla generazione e alla modifica di Mappe con baking, come Normalmap o AO e Curvatura. Alcuni esempi:

* [Curvatura uniforme](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/curvature-smooth/curvature-smooth.md)
* [Occlusione ambientale (HBAO)](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/ambient-occlusion-hbao/ambient-occlusion-hbao-filter-node.md)

Un altro gruppo di nodi è destinato all’effetto forma livello o &quot;Stili livello&quot;, come si vede in altri software di editing di immagini molto diffusi. Alcuni esempi:

* [Bagliore](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/glow/glow.md)
* [Tratto forma](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/shape-stroke/shape-stroke.md)
* [Rilievo Uber](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/uber-emboss/uber-emboss.md)

Infine, sono disponibili alcuni utili effetti avanzati, tra cui [Flood Fill](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/flood-fill/flood-fill.md), [Rilevamento bordi](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/edge-detect/edge-detect.md) e [Alterazione vettoriale](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/vector-warp/vector-warp.md).
