## Descrizione

Questo trasforma un’immagine di input alterandola in una direzione oscillante. Ha un controllo aggiuntivo per spostare il vortice in alcune parti dell&#39;area di lavoro.

## Parametri

* **Matrice**\
  Consente di spostare manualmente l’effetto Vortice. Può essere modificato anche interagendo con le maniglie nell’anteprima 2D.
  * **Matrice**: *(Matrice Di Trasformazione)*
  * **Scostamento**: *0,0 - 1,0*
* **Entità**: *-16.0 - 16.0* Intensità dell&#39;effetto di rotazione.
