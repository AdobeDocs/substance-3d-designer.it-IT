# Mappa normale

Questa categoria contiene solo nodi per l&#39;elaborazione e l&#39;utilizzo di mappe normali. Si tratta di un must assoluto quando si desidera che l&#39;elaborazione Normalmap sia matematicamente corretta, per evitare problemi di spazio tangente.

Utilizzare l&#39;<b>elenco di spostamento a sinistra</b> per sfogliare tutti i nodi sotto la Mappa normale.
