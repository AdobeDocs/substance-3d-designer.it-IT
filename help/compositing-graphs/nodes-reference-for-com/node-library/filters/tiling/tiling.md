# Affiancamento

La categoria affiancatura contiene nodi utilizzati per migliorare la suddivisione in porzioni delle texture. Tenere presente che per questa operazione sono disponibili altri nodi in [Elaborazione analisi](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md).

Utilizzare l&#39;elenco di spostamento a sinistra per sfogliare tutti i nodi in <b>In porzioni</b>.

In questa categoria sono presenti due nodi:

* [Imposta come patch porzione](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/make-it-tile-patch/make-it-tile-patch.md)
* [Crea foto in piastrelle](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/make-it-tile-photo/make-it-tile-photo.md)
