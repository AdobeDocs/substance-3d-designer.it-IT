# Fusione (materiale)

La categoria Fusione è una delle più importanti categorie di materiale multicanale. Contiene nodi destinati a combinare, commutare e miscelare materiali che consistono in molteplici output simultanei.

Questi nodi consentono di risparmiare una grande quantità di lavoro, ma è importante comprendere appieno le [modalità di creazione dei collegamenti](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) per utilizzarle correttamente.

I nodi seguenti sono quelli utili per iniziare:

* [Fusione multimateriale](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/multi-material-blend/multi-material-blend.md)
* [Blend di regolazione materiale](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-adjustment-blend/material-adjustment-blend.md)
