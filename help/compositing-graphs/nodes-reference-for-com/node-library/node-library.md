# Libreria nodi

Oltre ai [nodi atomici](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md), Designer include anche una libreria di [istanze del grafico](../../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md) predefinite, suddivise in molte categorie. Ce ne sono oltre 200 diversi, alcuni molto spesso utili, altri sono destinati a casi d&#39;uso molto specifici.In questa area della documentazione vengono descritti tutti i nodi della libreria e vengono forniti puntatori e suggerimenti utili per iniziare a utilizzare i nodi.

Il pannello Libreria di Designer visualizza più categorie di quelle attualmente documentate, In particolare i nodi MDL mancano, che potrebbero essere aggiunte in futuro.
