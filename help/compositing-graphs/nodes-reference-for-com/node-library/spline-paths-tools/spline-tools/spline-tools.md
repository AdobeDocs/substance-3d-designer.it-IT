# Strumenti spline

Gli Strumenti spline sono una raccolta di nodi per la generazione e la regolazione di spline e per il loro utilizzo per la mappatura, la dispersione o l&#39;alterazione delle immagini.

Le spline sono curve lisce le cui traiettorie sono modellate dai punti di controllo e dalle tangenti di tali punti. Ogni punto controlla inoltre gli attributi di height e thickness di una spline utilizzati per guidare la mappatura, l&#39;alterazione e la dispersione delle immagini.

Seguite questo tutorial per iniziare:

>[!TIP]
>
> Ti consigliamo di imparare a [utilizzare il percorso e gli Strumenti spline](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md) per sfruttare al meglio il set di strumenti.
