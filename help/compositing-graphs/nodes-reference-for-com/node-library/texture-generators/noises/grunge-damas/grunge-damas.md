## Descrizione

Il nodo **Damas Grungi** genera una mappa delle grungi simile a un pattern in acciaio di Damasco.

<a name="parameters"></a>

## Parametri

|  |  |
|:---|:---|
| <b>Saldo</b> <i>Mobile</i> | Regola il bilanciamento tra i valori di luminosità e oscurità. |
| <b>Contrasto</b> <i>Mobile</i> | Regola il contrasto dell’immagine. |
| <b>Inverti</b> <i>Booleano</i> | Inverte l&#39;output dell&#39;immagine utilizzando un&#39;operazione `1-x`. |
| <b>Non square expansion</b> <i>Booleano</i> | Consente la compensazione di schiacciamento e allungamento con rapporti non quadrati. |
| <b>Avanzate</b> |  |
| <b>Distorsione</b> <i>Mobile</i> | Regola la quantità di distorsione nel pattern. |
| <b>Divisioni</b> <i>Numero intero</i> | Regola la quantità di divisioni, o ripetizioni di sfumature, nel pattern. |
| <b>Onde</b> <i>Numero intero</i> | Regola la quantità di onde nel pattern. |
| <b>Dettagli</b> <i>Mobile</i> | Regola l’intensità delle distorsioni più piccole. |
| <b>Rotazione casuale</b> <i>Mobile</i> | Regola la casualità della rotazione per ogni onda. |
