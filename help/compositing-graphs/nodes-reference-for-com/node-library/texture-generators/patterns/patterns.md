# Pattern

I pattern sono grafica artificiale che sembrano fatti dall&#39;uomo. Seguono per lo più le regole per il loro posizionamento, ma la variazione casuale può essere introdotta la maggior parte del tempo.

Sono utili per quando si desidera un motivo regolare come base, come mattoni, piastrelle, motivi tessuti, ecc.

Quasi tutti i pattern sono perfettamente affiancati e sono indipendenti dalla risoluzione, il che significa che puoi ridimensionarli senza perdita di qualità.

Utilizzare l&#39;<b>elenco di spostamento a sinistra</b> per sfogliare tutti i nodi in Pattern.
