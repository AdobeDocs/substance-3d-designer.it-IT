## Descrizione

Genera un motivo a strisce Affiancamenti, angolati. Il pattern si regola da solo per garantire sempre continuità.

<a name="parameters"></a>

## Parametri

|  |  |
|:---|:---|
| <b>Stripe</b> <i>1 - 100</i> | Consente di impostare la quantità di strisce. Sposta automaticamente il risultato per garantire l&#39;Affiancamento. |
| <b>Larghezza</b> <i>0.0 - 1.0</i> | Imposta la larghezza della Stripe. |
| <b>Morbidezza</b> <i>0.0 - 1.0</i> | Imposta la transizione dei bordi della striscia. |
| <b>Maiusc</b> <i>0 - 20</i> | Inclina le strisce. Aggiunge automaticamente più strisce per garantire l&#39;Affiancamento. |
| <b>Allinea</b> <i>Bordi, centro</i> | Imposta il perno per lo spostamento. |
| <b>Filtraggio</b> <i>Falso/Vero</i> | Abilita i filtri. |
| <b>Non square expansion</b> <i>Falso/Vero</i> | Consente la compensazione di schiacciamento e allungamento con rapporti non quadrati. |
