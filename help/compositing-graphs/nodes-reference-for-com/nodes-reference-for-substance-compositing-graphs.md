# Nodi di riferimento per i grafici Substance

Poiché Substance 3D Designer è un software di creazione delle texture basato sui nodi, sono disponibili molti nodi diversi. In questa sezione vengono illustrati i diversi tipi e vengono documentati tutti i nodi forniti con il software.

Ciò che chiamiamo &quot;nodo&quot; all&#39;interno di SD, può essere diviso in 2 gruppi principali:

* [I nodi atomici](../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md), gli elementi costitutivi principali di qualsiasi grafico.
* [Istanze del grafico](../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md), nodi composti, di cui una vasta selezione di contenuti predefiniti è disponibile nella [libreria dei nodi](../../compositing-graphs/nodes-reference-for-com/node-library/node-library.md)
