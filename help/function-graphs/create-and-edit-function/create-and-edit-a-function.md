# Creare e modificare una funzione

## Creare una funzione

Per creare una funzione, è sufficiente fare clic sull&#39;icona della funzione ![](create-and-edit-a-function.resources/image2017-3-7-17-10-8.png) e scegliere &quot;**Funzione vuota**&quot;.

![](create-and-edit-a-function.resources/image2017-3-7-17-8-37.png)

## Modificare una funzione

Una volta creata una funzione, è possibile modificarla facendo di nuovo clic sull&#39;icona della funzione o scegliendo Modifica nell&#39;elenco a discesa.

![](create-and-edit-a-function.resources/image2017-3-7-17-11-42.png)

Si entra quindi nella modalità funzione del grafico.

## Grafico della funzione

Il grafico delle funzioni funziona come gli altri tipi di grafico in Designer: con un editor di nodi.

## Crea nodi

Potete creare nodi facendo clic con il pulsante destro del mouse nel grafico e scegliendo &quot;Aggiungi elemento&quot; o premendo la barra spaziatrice:

![](create-and-edit-a-function.resources/capture-d-e-cran-2015-02-04-10-05-16.png){width="600px"}

## Impostare un output

Contrariamente al grafico a Substance, la funzione non ha il nodo &quot;Output&quot;, è necessario specificare quale nodo del grafico è l&#39;output della funzione.

È possibile impostare un output facendo clic con il pulsante destro del mouse su un nodo e scegliendo <b>&quot;Imposta come nodo di output&quot;.</b>

Il set di nodi come output diventerà giallo.

>[!NOTE]
>
> **Tipo di output**
> 
> Il nodo che si desidera impostare come output deve contenere lo stesso tipo di valore del parametro controllato. In caso contrario, l’opzione &quot;Imposta come nodo di output&quot; sarà disattivata.

>[!WARNING]
>
> Per funzionare, una funzione deve disporre di un output. Verrà visualizzato un avviso nel grafico se la funzione non ha impostato alcun output.
