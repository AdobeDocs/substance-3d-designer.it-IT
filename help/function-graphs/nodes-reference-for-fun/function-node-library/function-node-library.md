# Libreria nodo di funzione

Oltre ai [nodi atomici](../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/atomic-function-nodes.md), Designer offre anche grafici preconfigurati delle funzioni Substance come nodi di istanza. Offrono molti strumenti per velocizzare il flusso di lavoro e fornire più funzionalità per lavorare con vettori o colori, modificare i valori, eseguire algebre più avanzate, ecc.

Questi strumenti sono suddivisi in diverse categorie:

<a name="sdf-functions"></a>

## Funzioni SDF

Questi nodi consentono di creare Funzioni SDF che possono essere utilizzate per generare forme 3D nei nodi [Splatter forme v2](../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) e [Visualizzatore 3D](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/3d-viewer/3d-viewer.md), utilizzando i relativi parametri **Funzione SDF** dedicati.

>[!INFO]
> 
> Per ulteriori informazioni sui concetti e i flussi di lavoro relativi alla Funzione SDF, consulta la pagina dedicata: [Utilizzo della Funzione SDF](function-nodes-sdf-functions/working-with-sdf-functions.md)
