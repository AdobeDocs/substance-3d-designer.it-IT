## Descrizione

Impostate l’ID materiale di una scena SDF.

Questo valore può quindi essere recuperato per tutte le forme SDF schizzate nell&#39;output *Splatter UVW* dello [splatter forma v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).
