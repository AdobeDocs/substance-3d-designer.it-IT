## Descrizione

Impostate la ruvidità del materiale di una scena SDF.

Questo valore può quindi essere recuperato per tutte le forme SDF schizzate nell&#39;output *Rugosità SDF* dello splatter [Forma v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).
