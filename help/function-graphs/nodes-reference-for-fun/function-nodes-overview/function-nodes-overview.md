# Panoramica sui nodi delle funzioni

Questa pagina fornisce una panoramica completa di tutti i nodi di funzione e spiega la codifica a colori utilizzata per i tipi di dati di funzione.È possibile fare clic su pagine più dettagliate con ulteriori spiegazioni.

Questi nodi di funzione sono accessibili facendo clic con il pulsante destro del mouse nell&#39;editor della funzione del grafico e scegliendo Elemento, premendo Barra spaziatrice o Tab in una funzione o tramite la sezione Funzioni della libreria.
