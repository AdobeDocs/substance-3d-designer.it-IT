# Che cos&#39;è un file Substance 3D?

![Materiale di parete di mattoni parametrici](../../../assets/MaterialsOverview.gif "Materiale di parete di mattoni parametrici")

*Esempio di materiale da parete in mattoni realizzato da Käy Vriend.\
I parametri possono essere modificati per controllare dinamicamente l&#39;aspetto del materiale.*

Un file Substance 3D è un generatore dinamico di texture, che può essere utilizzato direttamente in molte applicazioni.

È dinamico perché, a differenza di un file bitmap classico, l&#39;autore di un file Substance 3D può scegliere di <b>esporre i parametri</b> per fornire <b>controllo</b> del risultato finale che verrà generato.

Ad esempio, è possibile modificare la quantità di dust di un oggetto o il colore di una maglia della squadra di calcio. Il vostro talento e la vostra immaginazione sono gli unici limiti a ciò che potete fare.

È possibile pubblicare materiale di Substance da utilizzare in <b>applicazioni esterne</b> che integrano <b>Substance 3D Engine</b> (ad esempio *Unity* o *Unreal Engine*).

I materiali Substance 3D possono essere *100% procedurali*, pertanto la loro dimensione di output sarà molto leggera.
