# Editor Python

Substance 3D Designer include un **editor di script**, che consente agli utenti di **testare il codice Python** direttamente in Designer e ottenere il relativo **output della console**.

![Editor Python](../../assets/demo-pythoneditor.png "Editor Python")

L&#39;editor include una funzionalità &#39;**Trova e sostituisci**&#39;, accessibile nell&#39;elemento &#39;*Modifica > Trova...*&#39; nella barra dei menu dell&#39;editor oppure premendo *Ctrl+F*.

![Trova e sostituisci nell&#39;editor Python](../../assets/demo-pythoneditor-2.png "Trova e sostituisci nell&#39;editor Python")

Nello spirito degli **test** **scopi** dell&#39;editor Python, gli utenti possono testare tutto il codice premendo il pulsante &#39;*Esegui*&#39; nella barra degli strumenti dell&#39;editor (o premendo *F5*) oppure la **selezione corrente solo** premendo il pulsante &#39;*Esegui selezione*&#39; (o premendo &#39;*Ctrl+Invio*&#39;).

![Eseguire il codice selezionato nell&#39;editor Python](../../assets/demo-pythoneditor-3.png "Eseguire il codice selezionato nell&#39;editor Python")
