# Scripting

È possibile controllare l&#39;applicazione scrivendo plug-in. I plug-in possono essere scritti nel linguaggio di script **Python** utilizzando la versione **3.9**. L’API Python fornita nell’applicazione consente di accedere e utilizzare molte funzioni direttamente dagli script.

[Python](https://www.python.org/) è un linguaggio di scripting ampiamente utilizzato in molti settori. Tra gli altri esempi, aiuta a creare automazione, accelerazione dei flussi di lavoro e strumenti di gestione delle risorse. È possibile accedere alla documentazione API dal menu principale con l&#39;azione **Guida** > **Documentazione di scripting...**.
