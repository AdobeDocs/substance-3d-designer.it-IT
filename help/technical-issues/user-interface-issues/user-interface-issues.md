# Problemi dell&#39;interfaccia utente

In questa pagina vengono elencati i problemi tecnici relativi all&#39;[interfaccia utente](../../interface/interface.md) di Substance 3D Designer e vengono fornite le procedure per la risoluzione dei problemi per ciascuno di essi.

## La scala dell&#39;interfaccia non è corretta

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

**![(出错)](user-interface-issues.resources/error.svg) Problema**

Gli elementi dell&#39;interfaccia utente sono troppo piccoli o troppo grandi.

</td>
<td style="border: 0;" valign="top">

**![(滴答)](user-interface-issues.resources/check.svg) Passaggi consigliati**

Designer acquisisce la scala specifica degli elementi dell&#39;interfaccia utente *dal sistema operativo*. Pertanto, qualsiasi regolazione del ridimensionamento dell&#39;interfaccia utente deve essere effettuata nelle impostazioni di visualizzazione del sistema operativo.

Per garantire che le impostazioni di visualizzazione vengano applicate correttamente in Designer, *esci* dalla sessione utente del sistema operativo ed effettua nuovamente l&#39;accesso dopo aver modificato queste impostazioni.

</td>
</tr>
</table>
